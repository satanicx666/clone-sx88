# Behaviors & Interactions - sx88.cfd

- **Sticky Header**: The main navigation bar sticks to the top of the viewport on scroll.
- **Swiper Banners**: Automatic slide transition with navigation dots/arrows.
- **Tab Switching**: Game categories dynamically filter the game grid without a full page reload.
- **Hover Effects**: Game cards zoom slightly and display a "Mainkan" (Play) or "Demo" overlay on hover.
